# RD-APP: Чепош Парк

Интерфейс бронирования путешествий с ИИ-агентом. React + TypeScript + Tailwind 4 + shadcn.

Виджет — рамка 393×812: обложка, штора с табами и панелями, агент, плеер, разговор.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/index.html
npm run preview  # посмотреть собранное
```

## Как устроен перенос

Это главное, что нужно понять перед правками.

`legacy/ChiposhPark.html` разложен на три части:

| Часть | Куда | Как |
|---|---|---|
| CSS, 895 строк | `src/styles/chiposh.css` | без единой правки |
| Разметка, 343 строки | `src/components/*.tsx` | классы и `data-*` сохранены |
| Логика, 1804 строки | `src/lib/chiposhRuntime.js` | целиком, как есть |

**Логику не переписывали.** `chiposhRuntime.js` — это последний `<script>` из
исходного файла. Правок в нём четыре: обёртка в `initChiposh()` для вызова из
`useEffect`, импорт `STAR_ANIMS` вместо глобальной переменной, защита от
повторного запуска и мостик `chiposh` наружу.

Файл оставлен `.js` намеренно: это ES5-код, который под strict-TypeScript
пришлось бы править, а править его нельзя — он определяет поведение.

### Кто чем владеет

React рисует разметку **один раз** и больше в неё не лезет. Дальше часть
контейнеров наполняет рантайм:

- билеты — `[data-ticket]`, собираются из `TICKETS`
- часы погоды — `#days`
- пины карты — набор меняется вместе с часом на линейке
- клавиатура — `[data-kb]`
- лента сообщений — `[data-msgs]`
- лента фильмов — детей `#films` рантайм клонирует в три набора
- панели 5.07 и 6.07 — копии панели «Сегодня» со своими числами

**Поэтому в этих местах нельзя добавлять React-состояние**: перерисовка
затрёт то, что положил рантайм.

Исключение — табы: их состояние держит React, рантайму остаётся переключение
панели через `chiposh.show(key)`.

### Правило про классы

Классы `.pill`, `.nav`, `.li`, `.tab`, `.chip`, `.ev`, `.book-x` и подобные —
не только оформление. По ним рантайм находит элементы. **Снимешь класс —
отвалится поведение.**

## shadcn

Настроен: `components.json` — vite / ts / base ui / nova / lucide / алиас `@`.

### Добавить компонент

```bash
npx shadcn@latest add dialog
```

Файл придёт в `src/components/ui/`. Там лежат **оригиналы** — правится только
путь импорта `cn`, это делает сам установщик.

### Как надевать на вёрстку

Компоненты shadcn рассчитаны на обычную страницу, а здесь всё внутри рамки
393×812. Готовый компонент почти всегда нужно подгонять снаружи, **не трогая
его файл**:

```tsx
// вид проектный, поведение библиотечное
<Button variant="ghost" className="nav">Удобства в номере<i>›</i></Button>
```

Работает это так: `chiposh.css` подключён вне слоёв Tailwind, а неслоистый CSS
в каскаде стоит **выше** утилит. Поэтому `.nav` перебивает классы библиотеки
сам собой.

Где не перебивает — гасим утилитой снаружи. Реальные случаи из проекта:

- `w-full justify-start` вместо `w-fit justify-center` на ряду табов
- `min-w-0` на обёртке табов: `Tabs` — флекс-контейнер, без этого ряд распирал
  рамку вместо прокрутки
- `justify-start` на пунктах списка: библиотечная кнопка центрирует содержимое

**После каждого компонента — смотреть глазами.** Копирование не равно готово.

### Что уже внедрено

| Что | Компонент |
|---|---|
| Табы | `Tabs`, вариант `line` |
| Времена брони | `ToggleGroup` |
| Все кнопки виджета | `Button` |

### Что брать не надо

- **Чипы** — правила проекта запрещают `Badge`
- **Стопка вариантов, лента фильмов, карта** — своя моторика на пружинах
- **Табы в виде серой капсулы** — только вариант `line`

## Токены

`src/styles/theme.css`. Дефолты shadcn проекту не годятся ни одним значением,
поэтому переопределены явно.

| Роль | Значение |
|---|---|
| ink, основной текст | `#060708` |
| вторичный текст | `rgba(6,7,8,.4)` |
| волосяные линии | `rgba(6,7,8,.1)` |
| подложка тегов | `#F0F5F7` |
| акцент, добавил агент | `#EFFF5D` |
| мятный, блеск «думает» | `#34DDC6` |

**Радиус не один на проект**, а по компонентам: медиа 12, чипы 12, пилюли 18,
пилюли брони 22, панель агента 20, тег брони 14.

**Карточки плоские** — без бордеров и теней. Колец фокуса нет.

В старых экранах из бандла встречается ink `#14202A` — это наследство, новая
работа идёт на `#060708`.

## Куда подключать бэкенд

Сейчас все ответы агента — заглушки в `src/lib/chiposhRuntime.js`:

| Что | Где |
|---|---|
| ответ на вопрос в чате | `agentReply()`, строка ~626 |
| подсказки в пустом чате | `HOTEL_FAQ`, ~617 |
| подсказки «что взять» | `PACK_HINTS`, ~618 |
| варианты замены события | `PLAN_SWAP` / `PLAN_ASK`, ~997 |
| событие, которое добавляет агент | `NEW_EV`, ~1421 |
| реплики под блоками | пропсы `follow` и `done` у `<Nudge>` |

Сценарий агента везде один: предложение → выбор → «думает» → результат от
первого лица («Записал…», «Забронировал…»). При подключении API этот порядок
надо сохранить, меняется только источник текста.

## Проверка после правок

Виджет сверяется с `legacy/ChiposhPark.html` — он источник истины.

```bash
python3 -m http.server 5000
# http://localhost:5000/legacy/ChiposhPark.html  — как должно быть
# http://localhost:5000/dist/index.html          — как получилось
```

Смотреть: панели, табы, билеты, пины, линейку, ленты, ноджи, стопки,
клавиатуру, разговор. Расхождений быть не должно.
