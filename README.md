# agent-kit

Общий кит виджетов для агентных интерфейсов. Один репо, две точки входа:

- **Галерея** — живой каталог виджетов с кодом. Открываешь, смотришь как выглядит
  виджет во всех состояниях, копируешь код.
- **Компоненты** — файлы в `src/components`, единственный источник правды.

## Запуск галереи

```bash
npm install
npm run dev        # локально
npm run build      # прод-сборка в dist/
```

Публичная версия деплоится на GitHub Pages автоматически при пуше в `main`
(см. `.github/workflows/deploy.yml`). Включи Pages в настройках репо:
Settings → Pages → Source: GitHub Actions.

> `vite.config.js` -> `base` теперь относительный (`"./"`), поэтому Pages
> работает при любом имени репозитория. Переименуешь репо — ничего править
> не нужно.

## Две кнопки копирования

У каждого виджета в галерее:

- **Импорт (Codex)** — сырой файл. Для реального проекта: `import { AgentMessage } ...`
- **Для артефакта** — самодостаточный кусок с вклеенными токенами и зависимостями.
  Вставляется в single-file артефакт claude.ai, где импорт локальных файлов не работает.
  Внешние импорты (react, framer-motion) идут подсказкой в комментарии сверху.

## Добавить виджет

1. Положи файл в `src/components/MyWidget.jsx`. Токены бери из `tokens/tokens.js`.
2. В `src/registry.js` импортируй компонент и его исходник:
   ```js
   import MyWidget from "./components/MyWidget.jsx";
   import MyWidgetRaw from "./components/MyWidget.jsx?raw";
   ```
3. Добавь запись в нужную секцию с наборами `states`. Галерея подхватит сама.

## Работа на двоих

- Ветка на фичу, PR, ревью. Прямых пушей в `main` нет.
- Смена API виджета — строка в `CHANGELOG.md`.
- Виджеты отдельными файлами, не один монолит: диффы читаемые, конфликтов почти нет.

## Токены для SwiftUI

```bash
npm run tokens:json   # генерит tokens/tokens.json из tokens.js
```

Правила для ассистентов (переиспользование, анимации) — в `CLAUDE.md`.
