# RD-APP

Дизайн-разработка приложения с ИИ-агентом (ККР). Здесь живёт **эталонная сборка
интерфейса** — рабочий прототип, по которому сверяется всё остальное.

Продуктовая часть (что это, зачем, как устроен агент) — в
[«Описание проекта RD.md»](./Описание%20проекта%20RD.md). **Прочитать первым.**

---

## Что редактируем

```
ChiposhPark.html   ← ЕДИНСТВЕННЫЙ файл, который правим
```

Всё остальное — производное. Один файл: разметка + стили + скрипт, без сборки
и без зависимостей. Открывается двойным кликом, работает офлайн.

## Где что лежит

| Путь | Что это |
|---|---|
| `ChiposhPark.html` | **Основа.** Актуальная сборка интерфейса |
| `assets/img/` | Картинки (28 файлов `.webp`), общие для всех версий |
| `versions/` | Снапшоты предыдущих сборок, только для чтения |
| `Описание проекта RD.md` | Продуктовый документ: суть, тезисы, модель сценария |

## Как вести версии

Перед крупной правкой — снять снапшот текущей основы:

```bash
sed 's|"assets/img/|"../assets/img/|g' ChiposhPark.html > versions/$(date +%F)-что-менялось.html
```

Имя файла: `ГГГГ-ММ-ДД-что-менялось.html`. Снапшоты ссылаются на `../assets/img/`,
поэтому открываются и работают прямо из папки. Файлы в `versions/` не правим.

## Запуск

```bash
python3 -m http.server 4173     # затем http://127.0.0.1:4173/ChiposhPark.html
```

Двойной клик по файлу тоже работает.

## Из чего собран интерфейс

Пять экранов-вкладок: **карта территории · Подготовка · Сегодня (+5.07, 6.07) · Выезд**.
Дни `5.07`/`6.07` не дублируются в разметке — это клоны вкладки «Сегодня» со своими
числами (см. в скрипте блок `5.07 / 6.07 reuse the day layout`).

Блоки интерфейса и якоря, по которым их искать (`data-*` атрибуты):

| Блок | Якорь | Что делает |
|---|---|---|
| Обложка | `.hero` | Фото с параллаксом, лого, даты |
| Табы | `[data-tabs]`, `[data-go]` | Прибитая строка вкладок |
| Карта территории | `[data-terr]`, `[data-plane]` | Перетаскиваемая карта с пинами |
| Шкала времени | `[data-ruler]`, `[data-track]` | Пины перестраиваются по часу |
| Авиабилет | `.tkt` | Карточка рейса, самолёт летит по маршруту |
| Заезд и номер | `[data-checkin]`, `.room` | Дата заезда, бунгало |
| Чек-лист | `.list`, `[data-add-ask]` | Что взять; «+» добавляет через агента |
| Карусель фильмов | `#films` | Зацикленная лента с инерцией |
| Погода | `.wx` | Почасовая и дневная лента |
| Карточка события | `.ev` | Заголовок, описание, медиа, теги |
| **Бронь** | `[data-bookrow]`, `[data-bookstate]` | Чипы времени → «проверяю» → статус |
| **Сообщение агента** | `[data-nudge]`, `[data-nudgetx]` | Спаркл ↔ баббл, добавляет события |
| Колода | `[data-deck]`, `[data-rest]` | Карточка раскрывается в список |
| Лента блюд | `.dishes` | Горизонтальный список с ценами |
| Аудиогид | `[data-player]` | Плеер: перемотка, ±15 сек, свайп вниз |
| **Чат агента** | `[data-ask]`, `.sheet`, `[data-kb]` | Шторка со своей клавиатурой ЙЦУКЕН |
| Лонг-тап | `[data-lpscrim]` | Удержание карточки → фокус → «изменить» |

Жирным — то, что реализует жизненный цикл агента из продуктового документа
(предложение → выбор → «думает» → итог) и сквозной чат.

## Правила

- **Не плодить сущности.** Сообщение агента — один компонент, везде одинаковый.
  Новое предложение агента = тот же компонент с другими данными.
- Синяя точка = «добавлено агентом», единый маркер по всему продукту.
- Один моушен-язык: изинг `--ease: cubic-bezier(.6,0,.4,1)`, пружины в скрипте.
- Картинки — только в `assets/img/`, ссылками. Base64 в разметку не вклеиваем:
  от него файл распухает и диффы становятся нечитаемыми.

## Состояние и что дальше

Сейчас основа — **чистый HTML/CSS/JS в одном файле, без сборки**.

Планируется переход на [shadcn/ui](https://github.com/shadcn-ui/ui) как единый
стандарт компонентов. Это **не подключение библиотеки, а смена платформы**:
shadcn/ui — это React + Tailwind + Radix, то есть потребуется сборщик (Vite)
и перенос разметки в компоненты. Текущий файл при этом становится эталоном,
по которому сверяют результат.

Что уже сделано для этого перехода:

- картинки вынесены из base64 в файлы — иначе их не подхватит ни один сборщик;
- убраны строительные леса (оверлеи для сверки с макетом, тулбар, режимы сравнения);
- блоки интерфейса размечены `data-*` якорями и описаны выше — это готовая карта
  того, что во что превращать.

Что из блоков ложится на готовые компоненты shadcn/ui, а что придётся оставить
своим:

| Своё → shadcn/ui | Остаётся своим |
|---|---|
| Табы → `Tabs` | Карта территории со шкалой времени |
| Чат-шторка → `Sheet`, `Input` | Сообщение агента (спаркл ↔ баббл) |
| Чипы времени → `ToggleGroup` | Обложка с параллаксом |
| Чек-лист → `Checkbox` | Растущий градиент заката |
| Колода → `Collapsible` | Клавиатура ЙЦУКЕН |
| Карусели → `Carousel` | Карточка авиабилета |
| Плеер → `Slider` | Лонг-тап с фокусом карточки |

Ветки-копии: `vanilla-no-shadcn` — состояние без библиотеки,
`archive/chiposh-booking-prototype` — предыдущий прототип на React/Framer Motion.
