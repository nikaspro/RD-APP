# agent-kit — правила работы для ИИ (Claude, Codex)

Этот файл читают ассистенты (Claude в claude.ai, Codex у второго дизайнера),
чтобы работать по одному закону. Держите его коротким и живым.

## Что это

Общий кит виджетов на двоих. Каждый виджет живёт одним файлом в `src/components`.
Единственный источник правды. Галерея (`npm run dev`) показывает виджеты вживую
и даёт две кнопки копирования:

- **Импорт (Codex)** — сырой файл, `import` в реальный проект.
- **Для артефакта** — самодостаточный кусок с вклеенными токенами, вставляется
  в single-file артефакт claude.ai (там нет импорта локальных файлов).

## Дизайн-система (не менять на глаз)

- Шрифт: Google Sans, фолбэк Inter. Минимальный размер 16px.
- Цвета: ink `#14202A`, accent `#0FA5D8`. Остальное в `tokens/tokens.js`.
- Карточки: суперэллипс-скругления, без бордеров и теней.
- Нет: моноширинных шрифтов, тяжёлых начертаний, цветных градиентных карточек,
  центрирования текста, градиентных затуханий у низа панелей, sticky-хедеров.

## Правило переиспользования (жёстко)

Не изобретать новый компонент для того, что уже есть в ките. Сначала смотрим
`src/registry.js`, берём готовое или расширяем его пропсами. Новый файл — только
если в ките нет ничего близкого.

## Изменения API идут через PR

Смена пропса или сигнатуры — только через pull request. В `CHANGELOG.md` одна
строка на изменение, например: `AgentMessage: variant теперь info | nudge | confirm`.
Так молчаливая правка не ломает чужой экран.

## Токены для SwiftUI

`npm run tokens:json` генерит `tokens/tokens.json` из `tokens.js`. Порт переносит
значения (изинги, длительности, стаггеры), рендер нативный.

# Инструкция по анимациям (правило переиспользования)

## Главное правило

Перед тем как создавать или дорабатывать любую анимацию, переход, эффект или
моушен, сначала проверить уже подключённые знания и скиллы на готовое решение
и переиспользовать его, а не изобретать заново. Кастом с нуля — только после
того, как поиск показал, что подходящего решения нет.

## Обязательный порядок (перед кодом анимации)

1. Поиск по знаниям проекта по сути задачи (scroll reveal, hover, loader,
   gradient background, page transition, glass, list stagger, easing curve,
   shader aurora). Это первый шаг.
2. Проверить подключённые репозитории:
   - `0xjitsu/claude-shaders` (jitsu-shaders): 12 WebGPU-пресетов + каталог
     20+ слоёв-эффектов (`references/effect-catalog.md`), дерево выбора,
     воркфлоу авторинга.
   - `iart-ai/motion-design-skills`: animation-principles, motion-art-direction,
     color-motion, shot-composition, after-effects, beat-sync-editing,
     remotion-video, logo-animation, motion-background.
3. Проверить установленные скиллы: `gsap-plugins`, `motion-framer` и любые новые.
   Использовать их API, а не свои велосипеды.
4. Сопоставить задачу с готовым решением и взять его. Частичное совпадение —
   брать за основу и адаптировать.
5. Кастом — только если пункты 1–3 не дали решения. Тогда по принципам из
   animation-principles / motion-art-direction, а не на глаз.

## Задача → ресурс

- Изинги, тайминги, стаггер, spring vs duration → animation-principles
- Моушен-язык, тон, иерархия Hero/Support/Texture → motion-art-direction
- Цвета, градиенты, перцептивная интерполяция (OKLCH/Lab) → color-motion
- Живой фон: mesh-градиент, GLSL-аврора, частицы, луп → motion-background
- Hero/лоадер/переход/glass/scroll-reveal/постобработка → jitsu-shaders
- Плагины GSAP (Flip, Draggable, DrawSVG, MorphSVG, MotionPath, CustomEase) → gsap-plugins
- Framer Motion (variants, gestures, layout, AnimatePresence, springs, scroll) → motion-framer
- Логотип-ревил, стингер, сплэш → logo-animation
- Композиция, safe-area, кадрирование → shot-composition
- Программное видео (React → MP4/GIF) → remotion-video
- Правки в After Effects → after-effects
- Монтаж под музыку, ритм → beat-sync-editing

## Рантайм

- Артефакт claude.ai: доступен three (r128), gsap через скилл, Framer Motion,
  canvas/WebGL. Пресеты jitsu-shaders напрямую не заведутся (нет
  @basementstudio/shader-lab, WebGPU не гарантирован) — воспроизводить логику
  эффектов руками на Three.js/WebGL/canvas по effect-catalog.md. Всегда закладывать
  фолбэк: нет WebGL/шейдера — тихий откат на CSS/Framer-версию.
- Реальный Next.js (Codex): jitsu-shaders целиком по quick start.
- SwiftUI-порт: переносить принципы и параметры, рендер нативными средствами.

## Дисциплина

- Не дублировать то, что есть в репозиториях/скиллах. Сначала поиск — потом код.
- Один моушен-язык на весь продукт: одна семья изингов, базовая единица
  длительности, семья переходов, ритм стаггера, бюджет интенсивности.
  База проекта: `cubic-bezier(0.60, 0.00, 0.40, 1.00)` 300ms + пружины Framer.
- Перф-правила motion-background: кэп devicePixelRatio на 2, пауза оффскрин/скрытой
  вкладки, prefers-reduced-motion.
- Решение взято из репозитория/скилла — коротко указать источник в ответе.

## Само-проверка перед выдачей анимации

- Прогнал поиск по задаче?
- Проверил оба репозитория и установленные скиллы?
- Взял готовое (или адаптировал), а не изобрёл заново?
- Учёл рантайм и заложил фолбэк?
- Движение в едином моушен-языке проекта?
