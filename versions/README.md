# Версии

Снапшоты сборки интерфейса. **Только для чтения** — правим всегда
`../ChiposhPark.html`, сюда кладём копию «как было» перед крупной правкой.

Имя файла: `ГГГГ-ММ-ДД-что-менялось.html`.

Снять снапшот текущей основы (из корня репозитория):

```bash
sed 's|"assets/img/|"../assets/img/|g' ChiposhPark.html > versions/$(date +%F)-что-менялось.html
```

Картинки не копируются: снапшоты ссылаются на общий `../assets/img/`, поэтому
папка не распухает, а старые версии открываются и работают.
