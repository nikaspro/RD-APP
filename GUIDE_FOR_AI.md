# Чепош Парк — интерактивный прототип. Гайд для нейросети

Это гайд для ИИ-ассистента, который продолжит работу над прототипом мобильного приложения бронирования эко-отеля «Чепош Парк» (Горный Алтай) с AI-агентом. Прочитай его целиком перед правками.

---

## 1. Что это

Один React/JSX-файл — `ChiposhBooking.jsx` (~1.3 МБ, фото вшиты как base64). Это мобильный прототип экрана брони в фрейме телефона 393×812. Главная идея — интерфейс управляется **AI-агентом**: он предлагает действия, «думает», добавляет события в план, оформляет доставку и т.д.

В комплекте также готовый `Чепош Парк — прототип.html` — самодостаточная сборка (React + Framer Motion вшиты), открывается двойным кликом в браузере. Для стилей нужен интернет (Tailwind подгружается с `https://cdn.tailwindcss.com`).

---

## 2. Рантайм и зависимости

- **React 18** + **Framer Motion 11** (`motion`, `AnimatePresence`, `useMotionValue`, `useTransform`, `useScroll`).
- **Tailwind CSS** — утилитарные классы (`flex`, `items-center`, `rounded-full`, `absolute`, `grid grid-cols-2` и т.п.). В сборке — через CDN.
- Верх файла: `import React, { useState, useRef, useEffect } from "react";` и `import { motion, AnimatePresence, useMotionValue, useTransform, useScroll } from "framer-motion";`
- `lottie-web` подгружается в рантайме (для `LottieStar`), со встроенным SVG-фолбэком — интернет не обязателен для работы прототипа.

Чтобы запустить локально: Vite + React, положить файл в `src/`, отрендерить `<ChiposhBooking />`, подключить Tailwind (проще всего скриптом CDN в `index.html`).

---

## 3. Как править файл (важно)

Файл большой, правки делаются **точечными заменами строк** (не переписывай весь файл). Рекомендованный процесс:
1. Найди точную строку/блок (grep / чтение).
2. Замени через строковую замену (в Python — `str.replace`, проверяя, что вхождение ровно одно).
3. **После каждой правки проверяй синтаксис** парсером Babel:
   ```
   node -e "const P=require('@babel/parser');P.parse(require('fs').readFileSync('ChiposhBooking.jsx','utf8'),{sourceType:'module',plugins:['jsx']})"
   ```
   и баланс скобок `{}` и `()`.
4. Не изобретай новые сущности без нужды — переиспользуй существующие компоненты (особенно `AgentPanel`).

## 4. Дизайн-система

**Токены** (`const tokens`): background `#FFFFFF`, surface `#FFFFFF`, elevatedSurface `#F3F3F6`, primaryText/ink `#14202A`, secondaryText `#697079`, tertiaryText `#A2A7AF`, separator `rgba(20,32,42,0.08)`, акцент/синий `#353AFF`.

**Шрифт** — Geologica (веса 400/500/600/700, ровно четыре).

**Типографика** (`const T`): `display` 26/700; `section` 19/600 (эталон заголовка); `heading`/`title` 16/600; `body`/`secondary` 14/400; `meta` 12.5/400.

**Пружина**: `SPRING = { type:"spring", stiffness:380, damping:30 }`. Изинги: `EASE=[0.6,0,0.4,1]`, мягкий `[0.4,0,0.2,1]`, раскрытие `[0.33,0,0.15,1]`. Варианты появления: `RISE` (снизу с пружиной) и `STAGGER` (стаггер детей).

**Правила стиля**: без теней на карточках, без бордеров у карточек, углы скруглены, минимум декора. Плашка агент-сообщения — градиент `linear-gradient(120deg, #D1FFEB 0%, #D1FFFA 100%)`.

## 5. Главный компонент — `AgentPanel` (переиспользуй везде)

Единое «информационное сообщение от агента». Флоу: сообщение → выбор → кнопка → «думает» (статусы с бегущим градиентом, `ADDING_STATES`) → итог.

**Пропсы:**
- `items` — массив строк (варианты выбора).
- `title` — текст сообщения агента (заголовок, регуляр 15px).
- `doneTitle` — заголовок итога.
- `primaryLabel` — подпись кнопки (по умолчанию «Добавить»).
- `single` — режим одиночного выбора: чипсы круглые (radius 999), тап сразу запускает «думает» без нижней кнопки. Без `single` — мультивыбор: чипсы radius 6 + кнопка снизу.
- `checklist` — выбор в виде чекбоксов (кружки), а не чипсов.
- `detail` — если задан, появляется чип «Подробнее»; по тапу текст печатается (typewriter) в сообщении.
- `onClose` — колбэк крестика. Если не задан, крестик всё равно есть и прячет виджет сам.
- `onDone(selected)` — вызывается при переходе в итог; отдаёт массив выбранного.
- `doneMessage` — итог показывается **текстом на плашке** (в рамке) с крестиком: `doneTitle: пункты через запятую`. Без него итог — список.
- `doneChecklist` — итог показывается **чек-листом**: пункты с кружками, изначально **пустыми**, отмечаются по тапу.

**Состояния внутри**: `stage` = "select" | "adding" | "done". В "adding" виджет сжимается (только бегущий статус), чипсы/кнопка скрыты. В "done" по умолчанию плашка исчезает и остаётся чистый список + «Изменить»; при `doneMessage`/`doneChecklist` — как описано выше.

**Примеры использования в коде:**
- Домик: `<AgentPanel doneMessage items={ACTIVITY_ITEMS} title="Отметьте, что нравится — соберу идеальный план" doneTitle="Обновил план — добавил на 15 августа" onDone={(sel)=>{setPlanAdded(sel);setPlanBadge(true);}} onClose={...} />`
- Баня (single): `<AgentPanel single doneMessage onDone={(sel)=>setBanyaTime(sel[0])} items={["18:00",...]} title="Предлагаю сходить в баню вечером…" doneTitle="Записал баню на вечер" detail="…" />`
- Выезд: `<AgentPanel doneChecklist items={DEPART} title="Подготовлю всё к выезду — отметьте, что нужно, и я организую" doneTitle="Организую к выезду" primaryLabel="Отправить" />`

## 6. Остальные компоненты

- **DeliveryCard({ onMenu })** — плашка «Могу заказать доставку еды прямо в номер» + круглые кнопки «Смотреть меню» (→ `onMenu`) и «Позже», крестик.
- **MenuSheet({ open, onClose, onAdd })** — боттом-шит меню доставки. Табы категорий сверху (стиль как у главных табов, ink активный, скролл-спай + тап скроллит к секции), контент по секциям (данные `MENU`), карточки `BreakfastCard` (сетка 2 колонки). Отступы 16px, gap 4, блоки через 40px, заголовки секций скрыты.
- **BreakfastCard({ d, onAdd })** — карточка продукта: фото сверху (без нижних скруглений), подложка 3% чёрного на весь элемент, вес вплотную к заголовку, цена слева внизу + кнопка «+» справа. Колонка на всю высоту (цены выровнены по низу).
- **AgentReplyDialog({ open, message, onClose })** — шторка по кнопке «?». Над шторкой — равнозначные пилюли-подсказки (частые вопросы `HOTEL_FAQ` + «Позвонить на ресепшн»), появляются снизу вверх, скрываются при вводе. Инпут с клавиатурой (ЙЦУКЕН, `Keyboard`), крестик при пустом поле / стрелка при вводе. Переписка `msgs` (роли user/agent): моё сообщение вылетает справа (ink), ответ агента появляется слева через ~0.9с (контекстные ответы `agentReply`). Лента с ограничением высоты (52vh) и автоскроллом.
- **Widget({ item, last, onInfo })** — строка-карточка события: `MediaThumb` (фото) + заголовок + описание + расстояние отдельной строкой; тег «на территории отеля» (`item.check`, `item.status`). Искра отключена.
- **Twinkle / LottieStar** — анимированная звезда (lottie `star_pulse` + SVG-фолбэк). Сейчас в UI почти не используется (заменена на синие точки `#353AFF`).
- **WeatherWidget** — почасовая лента погоды (без строки состояния).

## 7. Структура приложения

Компонент `ChiposhBooking()` — фрейм телефона + герой (фото типи с параллаксом, лого «ЧЕПОШ-ПАРК» по центру, кнопка «?» справа-внизу: белая, обводка 10% чёрного, без тени) + липкие табы + контент.

**Табы** (`const TABS`): «Мой домик» (иконка домика) · «Перед заездом» · «15 авг» · «16 авг» · «Выезд». Индексы `tab` 0..4.

**Контент по табам:**
- `tab 0` (Мой домик): «Панорамик Хаус» + удобства списком; ниже по скроллу — AgentPanel «Отметьте, что нравится» (обновляет план).
- `tab 1` (Перед заездом): блок «Заезд» (подпись + «Пятница, 14 авг · 12:00» + «Панорамик Хаус · 2 гостя»), под ним AgentPanel раннего заезда (обновляет время в блоке через `earlyCheckin`); «Что взять с собой» (чек-лист `PACK`); AgentPanel подготовки дома.
- `tab 2 / 3` (дни, `DAY_PLANS[2]`/`[3]`): погода + блоки Утро/День/Вечер (карточки `Widget`, макс 3). На 15 авг (tab 2): завтрак «Шведский стол», плашка доставки (`DeliveryCard`), баня-AgentPanel перед «Вечер у костра», добавленные из плана события (`planAdded`, синяя точка справа → сообщение агента). На 16 авг (tab 3): плашка «Конная прогулка» + чёрная кнопка «Записаться».
- `tab 4` (Выезд): AgentPanel `doneChecklist` — подготовка к выезду.

**Ключевое состояние**: `tab`, `planAdded`/`planBadge` (обновление плана + синяя точка на табе «15 авг»), `banyaTime`, `earlyCheckin`, `spark` (AgentReplyDialog), `menuOpen` (MenuSheet), `editKey`/`lpTimer`/`lpStart`/`focusedCardRef` (лонг-тап), `agentOpen`/`agentDismissed` (появление по скроллу), `scrollRef`.

## 8. Интеракции

- **Лонг-тап по карточке** (хелпер `lp(key, title, children)`): удержание 380мс → фокус (scale 1.03, z 30, остальные тухнут до 0.12) + backdrop (тап-мимо снимает) + кнопка-карандаш «Изменить» → `openCardEdit` (открывает диалог + плавно поднимает карточку к верху). Отменяется при движении пальца >10px. Применён к карточкам событий, завтраку, добавленным событиям.
- **Появление агент-виджетов**: двухфазно — сначала раздвигается пространство (высота 0→auto, ~0.42с, контент прозрачный = белый зазор), затем с задержкой (~0.52с) мягко проявляется контент. Для домика/перед-заезда — по доскроллу (`agentOpen`, >70px); для дневных — `whileInView`.
- **Обновление плана**: выбрал активности в домике → агент «обновил план» (текст на плашке) → синяя точка на табе «15 авг» → события разложены по времени дня с синей точкой (тап → сообщение агента о добавленном).

---

## 9. Правила и конвенции

- Один моушен-язык: пружина `SPRING`, мягкий изинг `[0.4,0,0.2,1]`, единая плашка-градиент для агента.
- Заголовок агент-сообщения — **регуляр** (не болд), размер основного текста (15px).
- Итог-состояния: `doneMessage` (текст в рамке) или `doneChecklist` (интерактивный список) или список + «Изменить» — выбирается пропсом.
- Синие точки `#353AFF` — маркер «добавлено агентом».
- Переиспользуй `AgentPanel` для любых новых агент-предложений, не плоди новые компоненты.
- Русский язык интерфейса, тон агента — деловой, от первого лица («Организую…», «Записал…», «Подготовлю…»).

## 10. Как открыть готовый прототип

Распакуй архив, дважды кликни `Чепош Парк — прототип.html` — откроется в браузере (нужен интернет для стилей). Файл `ChiposhBooking.jsx` — исходник для дальнейших правок.
